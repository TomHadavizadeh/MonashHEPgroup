title: Machine learning for real-time event selection at LHCb
level: [phd, honours]
areas: [lhcb]
prerequisites: Python; some experience with machine learning is helpful but not required.
---

LHCb reads out its detector at the full LHC collision rate and decides in
software, within milliseconds, which collisions to keep. You will develop and
benchmark machine-learning classifiers that can run inside this real-time
system. The aim is to improve the efficiency for rare *b*-hadron decays while
keeping within strict computing limits.
